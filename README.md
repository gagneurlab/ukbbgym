## Install pre-commit before committing any changes to this repo: <br>

**!! Setup pre-commit!!** so formatting and removal of jupyter notebook outputs is automatically done. <br>
1. `pip install pre-commit` #Install pre-commit <br>
   `sudo apt install pre-commit` #Install on the RAP <br>
2. `pre-commit install` #Install the hooks from the pre-commit config

Then, pre-commit will always run when you commit.
